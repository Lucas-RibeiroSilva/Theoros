Criadores: Gabriel Olímpio, Kayky Ribeiro, Lucas Ribeiro e Paulo Henrique Silva Ramalho.

Theoros Fichas de RPG é um sistema desenvolvido para web que permite a criação, edição, download e compartilhamento de fichas de RPG para utilização em campanhas e jogatinas do mesmo.

como rodar localmente: 

OBS: é necessário inserir os arquivos .env em ambas as pastas principais do projeto(frontend, backend) antes da instalação das dependências. 

1. Utilizar comando cd para entrar na pasta de backend;
2. Utilizar o comando npm i para instalar todas as dependências;
3. Utilizar o comando npm run dev para iniciar o sistema localmente;
4. repetir o mesmo processo com a pasta frontend.
